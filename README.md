# Portfólio Pessoal — Marcelo Larocca

## Versão visual ampliada

Inclui identidade visual em lilás e rosa, monograma ML, ícone da aba do navegador,
cartões redesenhados, seção de trajetória de aprendizado, perguntas frequentes
expansíveis e botão de retorno ao topo. Os textos continuam acessíveis sem JavaScript.

Envie **todos** os arquivos desta pasta ao GitHub, incluindo `enhancements.css`
e `favicon.svg`. Abra `index.html` para visualizar. O arquivo `enhancements.css`
concentra os novos estilos e deve ficar na mesma pasta do HTML e do CSS original.

As informações sobre formação e habilidades vieram do modelo acadêmico original;
revise-as para refletir a trajetória real de Marcelo antes de publicar. Configure também
o e-mail em `script.js` e o endereço do GitHub em `index.html`.

Projeto desenvolvido para a **Atividade Extensionista de Tecnologia Aplicada à Inclusão Digital**, do curso de Análise e Desenvolvimento de Sistemas.

O site apresenta competências, projetos e informações profissionais em uma interface responsiva e acessível. Também inclui um guia curto para incentivar estudantes e iniciantes a criarem sua presença digital com ferramentas gratuitas.

## Funcionalidades

- layout responsivo para celular, tablet e computador;
- modo claro e escuro com preferência salva no navegador;
- menu mobile;
- animações suaves com respeito à preferência de movimento reduzido;
- filtro de projetos por categoria;
- formulário que prepara uma mensagem no aplicativo de e-mail;
- estrutura semântica e recursos básicos de acessibilidade;
- publicação gratuita pelo GitHub Pages.

## Como executar

Não é necessário instalar dependências. Baixe o projeto e abra `index.html` no navegador. Para usar um servidor local no VS Code, instale a extensão **Live Server**, clique com o botão direito em `index.html` e escolha **Open with Live Server**.

## Personalização necessária

Antes de publicar:

1. Em `index.html`, revise nome, apresentação, habilidades, projetos e rodapé.
2. Troque `https://github.com/SEU-USUARIO` pelo endereço real do seu perfil ou repositório.
3. Em `script.js`, substitua `seu-email@exemplo.com` pelo e-mail que receberá as mensagens.
4. Se desejar, adicione novos projetos copiando um bloco com a classe `project-card`.

## Publicar no GitHub Pages

1. Entre em [github.com](https://github.com) e crie um repositório público, por exemplo `portfolio-marcelo-larocca`.
2. Clique em **Add file → Upload files** e envie `index.html`, `style.css`, `script.js` e `README.md`.
3. Confirme em **Commit changes**.
4. Acesse **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main`, pasta `/ (root)` e clique em **Save**.
7. Aguarde alguns minutos. O endereço será parecido com `https://SEU-USUARIO.github.io/portfolio-marcelo-larocca/`.
